\section{Functional Requirements}
\label{chap:requirements}
To organize and prioritize features in Hover, we have created three sets of functional requirements (FR) based on their importance; \textit{High}, \textit{medium}, and \textit{low}. This chapter will present and briefly explain the idea behind the categories.

\subsection{High Priority FRs}
High-priority Functional Requirements are needed for the game to function as intended. Consequently, the requirements in Table \ref{tab:FR_high} are the ones that we categorize as a must-have in the application before testing it on real users. Thus, all eight high-priority FRs are implemented in Hover.
\begin{table}[H]
    \centering
    \begin{tabularx}{0.95\textwidth}{|c|X|}
    \hline
        \textbf{\#} & \multicolumn{1}{c|}{\textbf{Functional Requirement}} \\ \hline
        \textbf{FR1} & The user should be able to create an account and log in. \\
        \textbf{FR2} & The user should be able to view and explore hover zones (i.e., geofences). \\
        \textbf{FR3} & The user should be able to track and publish activities.\\
        \textbf{FR4} & The user should be able to participate in challenges, create challenges, and see challenge progress. \\
        \textbf{FR5} & The user should be able to view friends’ activities, earned achievements, and completed challenges.\\
        \textbf{FR6} & The user should be able to compare their score with friends on a leaderboard. \\
        \textbf{FR7} & The user should be able to earn achievements for completing predefined tasks. \\
        \textbf{FR8} & The user should be able to increase an activity score by socializing. \\ \hline
    \end{tabularx}
    \caption{High priority functional requirements.}
    \label{tab:FR_high}
\end{table}

\subsection{Medium Priority FRs}
Medium priority FRs are requirements that should be implemented if we have time. They improve the game experience but are not crucial for the game to function as intended. Three of the medium priority FRs in Table \ref{tab:FR_medium}, FR9, FR10, and FR11, have been implemented.

\begin{table}[H]
    \centering
    \begin{tabularx}{0.95\textwidth}{|c|X|}
        \hline
        \textbf{\#} & \multicolumn{1}{c|}{\textbf{Functional Requirement}} \\ \hline
        \textbf{FR9} & The user should get notifications of important events. \\
        \textbf{FR10} & The user should be able to create a custom profile and visit their friend’s profile. \\
        \textbf{FR11} & The user should be able to interact with friends’ activities, earned achievements, and completed challenges. \\
        \textbf{FR12} & The user should be able to customize their list of friends. \\ \hline
    \end{tabularx}
    \caption{Medium priority functional requirements.}
    \label{tab:FR_medium}
\end{table}

\subsection{Low Priority FRs}
Low priority functional requirements are nice to have features. They could improve the game, but not in a dramatic way. In this project, the requirements categorized with low priority have not been implemented (see Table \ref{tab:FR_low}). However, they serve as good suggestions for further work, as we will describe later in Chapter \ref{chap:further_work}. 

\begin{table}[H]
    \centering
    \begin{tabularx}{0.95\textwidth}{|c|X|}
        \hline
        \textbf{\#} & \multicolumn{1}{c|}{\textbf{Functional Requirement}} \\ \hline
        \textbf{FR13} & The user should be able to earn real-world awards.\\
        \textbf{FR14} & The user should be able to evolve a character based on their score. \\
        \textbf{FR15} & The user should be able to log in using external services, Facebook, Google, Contacts, etc.\\ \hline
    \end{tabularx}
    \caption{Low priority functional requirements.}
    \label{tab:FR_low}
\end{table}

\subsection{Summary}
In this chapter, the functional requirements have been listed and categorized. The requirements are used when describing the game in Chapter \ref{chap:game_description}. Chapter \ref{chap:game_development} also includes a more detailed explanation of how the requirements have been used during the development process.
