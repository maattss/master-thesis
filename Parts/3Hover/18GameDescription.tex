\section{Game Description}
\label{chap:game_description}
In this chapter, a descriptive overview and screenshots from the mobile application will be presented. Figure \ref{fig:nav_bar} shows the bottom navigation bar in Hover, displaying the five main screens: Feed, Challenge, Hover, Leaderboard, and Profile. Additionally, there are signup and login screens in which unauthenticated users are faced when they open the application. We will start by describing the signup and login screens before continuing with the description of the five main screens.

\subsection{Sign Up and Login}
The first time a user opens the application, they are presented with a login screen as seen in Figure \ref{fig:login}. If the person does not have an account, they can navigate to the signup screen and create a new one. The user needs to select their chosen avatar, preferred username, and password to sign up. When they are satisfied with their selection, a new user is created by clicking the “Sign up” button, shown in Figure \ref{fig:signup}. The login and signup screens are both developed based on the first functional requirement (\textbf{FR1}), which states, \textit{“The user should be able to create an account and log in.”}
